# 内容资产

所有思想卡片、引文、来源、同义词和安全规则均受 schema 与版本控制约束。

当前 23 张种子卡片、Phase 5 第二批 72 张扩充卡片与第三批 96 张扩充卡片均由 AI 辅助起草，并依据产品明确决定标为 `approved`，共计 191 张，覆盖 382 个版本化现实场景。同义词、安全规则和安全回答文案仍为 `review`，不能进入生产构建；它们需要分别核对查询扩展风险、危机召回、误报与现实处置措辞，再独立批准。

```bash
pnpm content:validate
pnpm content:validate:production
```

普通校验用于开发阶段草稿；生产校验会额外要求至少 300 张卡片、每个主题至少 15 张、全部资产已审核且权利状态明确。
