# 内容资产

所有思想卡片、引文、来源、同义词和安全规则均受 schema 与版本控制约束。

当前 23 张种子卡片、Phase 5 第二批 72 张、第三批 96 张与第四批 109 张扩充卡片均由 AI 辅助起草，并依据产品明确决定标为 `approved`，共计 300 张；12 个主主题各 25 张，覆盖 600 个版本化现实场景。中文与英文同义词、安全规则和安全回答文案也已依据产品明确决定独立批准。英文索引不是另一套思想库，而是在构建时使用相同卡片 ID、来源与安全边界生成的确定性本地化投影。

```bash
pnpm content:validate
pnpm content:validate:production
```

普通校验用于开发阶段草稿；生产校验会额外要求至少 300 张卡片、每个主题至少 15 张、全部资产已审核且权利状态明确。
