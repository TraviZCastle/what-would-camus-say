# 评测集

`retrieval-gold.json` 当前包含 50 条问题：46 条相关性问题和 4 条明确无结果问题。每条相关性问题标注一个或多个允许进入 Top 3 的卡片 ID。

```bash
pnpm evaluate:retrieval
```

脚本在内存中从已审核卡片建立同一份 BM25 索引，计算 Top 3 召回率和无结果准确率。召回率低于 80% 或任一无结果问题被拼成正式结果时，命令失败。

`safety-gold.json` 包含 100 条风险正例和 20 条用于控制误报的语境负例，覆盖自伤、暴力、未成年人危险、诈骗胁迫、急性医疗危险和专业结论边界。

```bash
pnpm evaluate:safety
```

安全评测要求正例按正确类别分流的召回率为 100%；任何测试失败都会使命令失败。
