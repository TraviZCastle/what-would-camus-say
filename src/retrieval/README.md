# 浏览器内检索

Phase 2 使用确定性的字段加权 BM25：

1. Unicode NFKC 标准化、大小写和标点清理。
2. 中文受控词典匹配，并补充二字、三字片段。
3. 使用版本控制中的同义词表扩展查询。
4. 对关键词、别名、标题、场景、张力、原则、解释和边界分别计算 BM25。
5. 返回 Top 8 候选，选择一张主卡片和最多两张补充不同主题或张力的辅助卡片。
6. 只有通用问句片段、没有主题证据或分数不足时返回无结果。

参数和字段权重集中在 [`config.ts`](./config.ts)。只读索引由 `pnpm build:index` 离线生成到 `public/content/search-index.json`；用户提交问题时不会发送网络请求。

开发服务器访问 `/#retrieval-debug` 可查看标准化文本、原始分词、受控扩展词、字段命中和 Top 8 排名。该视图在生产构建中不可进入。

当前 50 条种子评测的 Top 3 召回率为 100%，无结果准确率为 100%。这只证明种子覆盖，不能替代 Phase 5 的至少 200 条真实风格评测。
